## What it does

- Palettes registered on the panel; each user picks one, or makes their own from three colours.
- A logo per palette, the same in light and dark mode or one for each.
- A palette picker for any schema, or a ready-made page.
- An optional shell: underlined tabs and, on a phone, lists instead of tables, edge-to-edge cards and a tab bar.
- Progress bars for tables, infolists and stats.
